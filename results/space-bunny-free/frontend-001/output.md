## 交付内容

一个滚动驱动的「一镜到底」叙事页，用同一条时间轴连续装配出整条算力链，并把四层软件结构送进 Agent 窗口。

八个章节（固定顺序）：芯片 → 显卡/加速卡 → 服务器 → 机柜 → 集群 → 大模型 → Harness → Agent，底部附三项服务总结（大模型部署 / Harness 构建 / Agent 开发）。

**核心技术决定**（README 里有完整推导）：

- 页面只有一个状态量 `p ∈ [0,1]`（滚动进度）。相机、每个物体的世界坐标、每章权重、窗口变形全部是 `f(p)` 的纯函数 —— 因此「上滑必然沿原路返回」不是靠状态机，而是求值同一个函数。
- 物体身份是结构性的：场景树 `chip → card → server → rackA → cluster` 一次建好、永不重建。装配只改 `parent`，不销毁任何对象。
- 镜头注视点由「构图重心」实时决定（已落位权重 1、正在飞权重 0.35），不是手调关键帧。
- 自研等距 2.5D 渲染器（Canvas 2D），画家算法 + 逐面背面剔除。
- 字体为 OFL-1.1 可变字体（Noto Sans SC / Inter），真实含 700 字重。

完整设计说明、目录结构、动画实现原理见 `project/README.md`；运行与验证命令见 `project/PROJECT.md`。
